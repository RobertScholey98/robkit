An app on React + Hono is a Hono server that renders React to HTML, run by Vite. `robkit add` writes a small working app: a table, routes that read and write it as the viewer, a page that shows it, and a test. This guide walks through those files, then adds a table and two routes of your own.

## Add the app

With `pnpm dev` running, in the install's folder:

```sh
pnpm robkit add notes --stack react-hono
```

With `--stack` given, it asks nothing. It writes `apps/notes`, open to the owner alone and with the default icon, and starts it at `http://notes.robkit.localhost:3000`. Add `--access` and `--icon` to choose who may open it and its emoji, or leave out every option to be asked. The folder's name is the app's slug. It names the subdomain, and the Postgres schema and role too.

## The routes

`src/routes.tsx` builds the app's routes on a Hono app:

Each handler reads who is asking as `c.var.viewer`, which the guard set. The page changes nothing, and the form posts to `/visits`, which records the visit. The guard refuses a write from another app's page, but it can't refuse a `GET`, which a link can send. So the app changes state only on a `POST`. The rest of the file is two small helpers, `visitorId` and `headingFor`, and the `Page` component, which uses the install's shared UI kit from `@internal/ui`.

## The server

`src/server.tsx` puts the guard in front of the routes:

<TemplateFile path="stacks/react-hono/src/server.tsx" app="notes" />

`guarded()` reads the app's slug and core's address from the settings `pnpm dev` sets, and asks core for the app's access rule. Anyone the rule leaves out never reaches a route. Under `pnpm dev`, Vite hands this app each request it doesn't answer itself. In production, `src/serve.ts` serves it with Node.

## Make it yours

These steps give each viewer notes of their own: a table, its migration, the queries, two routes and their tests.

### Add a table

Declare it in `src/schema.ts`, below the example's `visit`. The file already imports these names.

```ts title="apps/notes/src/schema.ts"
import { pgTable, serial, text, timestamp } from "drizzle-orm/pg-core";

/** One row per note, by the viewer who wrote it. */
export const note = pgTable("note", {
  id: serial().primaryKey(),
  author: text().notNull(),
  body: text().notNull(),
  at: timestamp({ withTimezone: true }).notNull().defaultNow(),
});
```

Then write its migration, in the app's folder:

```sh app
pnpm db:generate
```

It writes the next file in `drizzle/`. Commit it.

### Apply the migration

In the install's folder, while `pnpm dev` runs:

```sh
pnpm robkit migrate notes
```

The app keeps running, and the table is there for its next query.

### Add the queries

Add `src/notes.ts`, which follows `src/visits.ts`:

```ts nocheck title="apps/notes/src/notes.ts"
import { desc, eq } from "drizzle-orm";
import { database } from "./database.ts";
import { note } from "./schema.ts";

/** What the routes store notes through. A test passes its own. */
export interface Notes {
  /** Adds a note by `author`. */
  add(author: string, body: string): Promise<void>;
  /** The notes `author` wrote, newest first. */
  list(author: string): Promise<string[]>;
}

/** Notes in the app's database. */
export const notes: Notes = {
  async add(author, body) {
    await database().insert(note).values({ author, body });
  },
  async list(author) {
    const rows = await database()
      .select({ body: note.body })
      .from(note)
      .where(eq(note.author, author))
      .orderBy(desc(note.at));
    return rows.map((row) => row.body);
  },
};
```

### Add the routes

In `src/routes.tsx`, take the notes as a second argument:

```tsx nocheck title="apps/notes/src/routes.tsx"
import type { Notes } from "./notes.ts";

export function routes(visits: Visits, notes: Notes): Hono<GuardedEnv> {
```

Then add two routes after `.post("/visits", ...)`. A `GET` lists the viewer's notes as JSON, and a `POST` adds one from a form field named `body`:

```tsx nocheck title="apps/notes/src/routes.tsx"
      // The viewer's notes, newest first.
      .get("/notes", async (c) =>
        c.json(await notes.list(visitorId(c.var.viewer))),
      )
      // Adds a note from a form field named body.
      .post("/notes", async (c) => {
        const { body } = await c.req.parseBody();
        if (typeof body !== "string" || body.trim() === "") {
          return c.json({ error: "Send the note in a field named body." }, 400);
        }
        await notes.add(visitorId(c.var.viewer), body);
        return c.json({ body }, 201);
      })
```

Each note is keyed by the viewer's id, so one viewer never reads another's. In an app open to anyone, everyone not signed in shares the id `nobody`. Pass the notes in `src/server.tsx`:

```tsx nocheck title="apps/notes/src/server.tsx"
import { notes } from "./notes.ts";

app.route("/", routes(visits, notes));
```

### Test them

In `src/routes.test.tsx`, keep notes in a list, as the test keeps visits, and hand them to the routes. Replace `appAs` with this:

```tsx nocheck title="apps/notes/src/routes.test.tsx"
import type { Notes } from "./notes.ts";

/** Notes kept in a list, in place of the database. */
function notesInMemory(): Notes {
  const kept: { author: string; body: string }[] = [];
  return {
    add: (author, body) => {
      kept.unshift({ author, body });
      return Promise.resolve();
    },
    list: (author) =>
      Promise.resolve(
        kept.filter((each) => each.author === author).map((each) => each.body),
      ),
  };
}

/** The app's routes as the server mounts them, with `viewer` asking. */
function appAs(viewer: Viewer, visits: Visits, notes = notesInMemory()) {
  const app = new Hono<GuardedEnv>();
  app.use(guardedAs(viewer));
  app.route("/", routes(visits, notes));
  return app;
}
```

Then test the routes as the owner and as a guest:

```tsx nocheck title="apps/notes/src/routes.test.tsx"
describe("notes", () => {
  it("keeps each viewer's notes, newest first, from the others", async () => {
    const notes = notesInMemory();
    const owners = appAs(owner(), visitsInMemory(), notes);
    const guests = appAs(guest({ roles: ["family"] }), visitsInMemory(), notes);

    for (const body of ["Buy milk", "Call the vet"]) {
      const added = await owners.request("/notes", {
        method: "POST",
        body: new URLSearchParams({ body }),
      });
      expect(added.status).toBe(201);
    }

    expect(await (await owners.request("/notes")).text()).toBe(
      '["Call the vet","Buy milk"]',
    );
    expect(await (await guests.request("/notes")).text()).toBe("[]");
  });

  it("refuses a note with no body", async () => {
    const res = await appAs(owner(), visitsInMemory()).request("/notes", {
      method: "POST",
      body: new URLSearchParams({ body: " " }),
    });

    expect(res.status).toBe(400);
  });
});
```

Run `pnpm test` in the app's folder again, and `pnpm lint` in the install's.
