A test of your app's code runs as a viewer the test builds. It needs no core, no database and no `pnpm dev`. Run `pnpm test` in the app's folder.

Each stack's adapter has a `/testing` entry for tests only. `owner()`, `guest({ roles })` and `nobody()` build a viewer, so a test never makes up an id. The example app's test shows how your stack hands it to your code, and keeps its visits in a list in place of the database.

## What covers the guard

Your app's test takes the guard as given. The guard has tests of its own. Every adapter, and Go's, runs the same cases, so each decides alike. robkit's whole-stack tests run a real install in a browser, and check what a viewer sees from sign-in to a refused write.
