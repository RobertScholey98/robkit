# Code samples

This page holds one code sample of each kind the docs show. The repo's checks read it, so you can see what they test.

## TypeScript

```ts title="addresses.ts"
import { installAt } from "@robkit/input/addresses";

const core = installAt("http://hub.robkit.localhost:3000/", "hub")?.origin(
  "core",
);
console.log(core);
```

## React

```tsx
import { useState } from "react";

export function Counter() {
  const [count, setCount] = useState(0);
  return (
    <button type="button" onClick={() => setCount(count + 1)}>
      Clicked {count} times
    </button>
  );
}
```

## Go

```go
package main

import (
	"fmt"
	"net/http"
)

func main() {
	http.HandleFunc("/", func(w http.ResponseWriter, r *http.Request) {
		fmt.Fprintln(w, "hello")
	})
	_ = http.ListenAndServe(":3000", nil)
}
```
